202604 logic:

analysis_sqlite.py

option4: basic option3, read the log, find the peer status, read the exist db, compaird, write the result to json, save/update db
The Option 4 Workflow
1. Parallel Read: Multi-thread/process the log files into memory.
two mode: 
- single/update mode: for single file for testing and update
- Directory mode: scan for all match log file under folder 

2. parse: filter all match log and routing info from the log

3. DB Context Fetch: Pull the current state of all peers from the database into a dictionary.

Comparison: Compare log data vs. DB data in memory (Latest Timestamp + State change).

4.JSON Staging: Write only the "Changed" or "Newer" results to a JSON lock file.

Atomic Sync: Batch update the database and backup the JSON.
